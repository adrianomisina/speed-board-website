# SPD Surfboards

Site institucional e portfólio de pranchas SPD Surfboards. É uma aplicação estática feita com React, TypeScript, Vite e Tailwind CSS; não requer backend, API ou variáveis de ambiente.

## Desenvolvimento

Requer Node.js 20 ou superior.

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
```

Os arquivos estáticos para publicação são gerados em `dist/` e podem ser hospedados em qualquer serviço de site estático.
